# Catalog module

- **Interface:** Catalog-path, configurable terminology, and curriculum-unit lookup interfaces.
- **Allowed dependencies:** Pure domain code, shared validation/types, and injected persistence interfaces.
- **Prohibited dependencies:** Hard-coded program screens, React/Next.js in domain files, and concrete database adapters in application files.
- **Owner:** The current catalog task agent; Ahmed or Ziad owns product terminology decisions.
