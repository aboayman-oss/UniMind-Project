# Studio module

- **Interface:** Source-grounded artifact requests, results, validation, and reuse contracts.
- **Allowed dependencies:** RAG evidence interfaces, usage interfaces, jobs, pure domain code, and shared validation/types.
- **Prohibited dependencies:** A second knowledge pool, unsupported claims, synchronous long work in requests, and concrete providers in application code.
- **Owner:** The current Studio task agent; academic reviewers own artifact-quality gates.
