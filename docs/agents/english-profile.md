# Ahmed's English profile

Use this profile for project communication. It is not a grammar score or a record of mistakes.

## Preferences

- Use English by default. Do not switch to Arabic unless Ahmed asks.
- Keep the technical level high, but explain uncommon words when they first matter.
- Prefer direct, natural, literal sentences over academic or corporate wording.
- Treat spelling and grammar mistakes as noise when the intended meaning is clear.
- Correct or teach English only when Ahmed asks.
- When wording is materially ambiguous, state the likely interpretation, ask one short question, and continue any safe work that does not depend on the answer.
- Use the canonical UniMind vocabulary in `CONTEXT.md` so the same idea keeps the same name.
- Use the `clear-english` skill when language blocks understanding or expression.
- Treat `$wait-what` as Ahmed's explicit command to re-explain the previous message from the missing context.
