# Safety module

- **Interface:** Educational-case, explicit real-patient, personal-data risk, and safe-response classification contracts.
- **Allowed dependencies:** Pure domain rules, approved policy inputs, and shared validation/types.
- **Prohibited dependencies:** UI-only enforcement, hidden provider policy, private examples in normal fixtures, and weakening approved refusals.
- **Owner:** The current safety task agent; policy owners approve material behavior changes.
