# UI components

- **Interface:** Reusable presentation and narrow interaction modules used by App Router surfaces.
- **Allowed dependencies:** Application interfaces, shared validation/types, React, and Next.js UI primitives.
- **Prohibited dependencies:** Domain implementations, concrete adapters, provider SDKs, service-role clients, and server-only modules from Client Components.
- **Owner:** The agent executing the current product-surface task; visual decisions remain governed by Impeccable and approved product context.
